# Как работают базы данных — интерактивный тренажёр

Одностраничное приложение для обучения основам баз данных: модели данных, реляционная модель,
связи и ER, нормализация, индексы, транзакции, запросы (SQL), нереляционные БД, масштабирование
и практические задачи. Всё интерактивно, работает целиком в браузере, без сервера.

## 🔗 Открыть

**https://andreypol1991.github.io/db-trainer/**

## Что внутри

- **Модели данных** — иерархическая, реляционная, документная, ключ-значение, графовая, колоночная
- **Моделирование** — концептуальная → логическая → физическая схема
- **Реляционные** — таблицы, ключи, ограничения, JOIN, целостность
- **Виды связей** — 1:1 / 1:N / N:M, ER-конструктор
- **Нормализация** — «нормализуй сам», аномалии интерактивно
- **DDL / SQL**, **Запросы** — SELECT, GROUP BY, оконные функции, подзапросы, CTE (с режимом «скрыть результат»)
- **Индексы** — B-tree, Hash, Bitmap, GIN, GiST, BRIN вживую; каталог видов и примеры
- **Транзакции** — ACID, аномалии изоляции по шагам
- **PostgreSQL** — как устроен движок, буферный кеш, путь записи на диск
- **Когда что**, **Масштаб**, **Основы**, **Песочница**, **Практика**
